Download the Android APK

Open the file on your phone and allow installs from unknown apps. Every build is signed with the same test key, so a new one installs over the old one.

Once installed, the game updates itself: it fetches each new build on launch and applies it on the next start (tap the build line at the top of the menu to restart right away). Only some builds, flagged in that line, need this APK again.

Play the 3D web version in the browser (the older version the Godot port is based on).
